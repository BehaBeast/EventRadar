# EventRadar — визуальное направление

Три векторные концепции: radar (событие рядом), pin (место), ticket (вход).
Выбран radar: он описывает поиск событий шире, чем продажа билетов.
SVG-файлы находятся в assets/branding. Светлая/тёмная версии логотипа готовы.

Основной фиолетовый #7047EB, светлый фон #FAF9FE, тёмный #121019.
Лаймовый #C6F476 используется только как небольшой акцент логотипа.
Типографика — системный Roboto с поддержкой кириллицы и узбекской латиницы.
Material Symbols/Icons — единая основа пиктограмм.

Компоненты: кнопки 52dp; карточки с радиусом 24dp; поля с радиусом 16dp;
отступы 8/12/16/20/24/32; контент не шире 800dp на планшете.
Тема системная, светлая и тёмная; ручной выбор сохраняется.
Текст не зафиксирован по высоте и учитывает масштабирование Android.

Фотографии событий ещё не подключены: до проверки загрузок/EXIF и Storage policies
не подставляются случайные иллюстрации под реальные события.
